# MedicalVet – Backend

Backend desarrollado con Laravel para un sistema de gestión veterinaria, orientado a la administración de pacientes, consultas clínicas, procedimientos, hospitalizaciones y procesos administrativos.

MedicalVet permite centralizar la información clínica de los pacientes y facilitar el seguimiento de sus atenciones dentro de una veterinaria.

## Funcionalidades principales

- Gestión de pacientes.
- Registro de consultas ambulatorias.
- Registro de procedimientos e intervenciones.
- Administración de consentimientos informados.
- Gestión de hospitalizaciones.
- Registro y seguimiento de medicamentos administrados.
- Gestión de facturación y generación de comprobantes de pago.

## Tecnologías utilizadas

- **Lenguaje:** PHP.
- **Framework:** Laravel 8.
- **Base de datos:** MySQL.
- **Autenticación:** JWT.
- **Generación de documentos PDF:** Laravel DomPDF.
- **Exportación de información a Excel:** Maatwebsite Excel.

## Arquitectura

Este repositorio contiene el backend de una aplicación web que expone servicios mediante una API REST, consumida por una interfaz desarrollada con Vue.js.
